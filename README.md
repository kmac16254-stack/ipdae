# 입대할게요 — 베타 0.4

모바일·PC 브라우저로 플레이하는 선택형 훈련소 게임입니다.

## 최초 GitHub Pages 설정

1. Settings → Pages를 엽니다.
2. Build and deployment의 Source를 **Deploy from a branch**로 선택합니다.
3. Branch를 **main**, 폴더를 **/ (root)**로 선택하고 Save를 누릅니다.
4. GitHub Pages 배포가 완료되면 https://kmac16254-stack.github.io/ipdae/ 에서 플레이합니다.

게임은 루트 index.html 하나로 실행됩니다. 이미지와 코드를 모두 포함해 외부 설치가 필요 없습니다. 원본 코드와 테스트는 game-source/에 있습니다. 이 저장소의 공개 범위는 public입니다.

## 베타 안내

- 훈련소 35일, 일별 타임라인, 당시 육군 21개월 복무 기준 전역 D-day.
- 상대와 내 대화를 세로로 배치하고, 교육 퀴즈와 관계·능력치 성장을 제공합니다.
- 진행은 이용자의 브라우저에 자동 저장되며 다른 기기로 동기화되지 않습니다.
- 경험담은 각 이용자 기기에만 저장됩니다. 파일로 내보내 제작자에게 전달할 수 있으며 서버로 전송되지 않습니다.
- 주특기 배정은 일반 특기 15개에 임시 게임 가중치를 사용합니다. 실제 2013년 배치 비율 통계가 아닙니다.
- 인물 사진은 생성한 가상 인물입니다. 훈련·사건·사단 직접 입영은 게임용 각색입니다.

## 개발

Node 24 권장. game-source/에서 npm run build, npm test로 빌드 및 검사를 실행합니다.
