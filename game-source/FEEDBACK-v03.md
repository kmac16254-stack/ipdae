# 베타 0.2 플레이 피드백 — 0.3 반영 기록

기록일: 2026-10-27 (한국 시간). 사용자 요청에 따라 피드백만 저장하며 이번 기록 단계에서는 게임 코드를 변경하지 않는다.

## 대화와 표기
- 대화 팝업에 이전 대사를 다시 읽는 뒤로가기 버튼을 제공한다. 되돌려 읽는 것으로 선택·능력치·이벤트 결과를 재실행하거나 취소하지 않는다.
- 생각·독백은 괄호로 표시해 실제 발화와 구분한다. 실제 발화의 화자와 독백의 주체도 명확하게 한다.
- 인물 이름 아래에 중복 표시되는 에피소드 주제는 제거한다. 에피소드 제목은 창 상단에 한 번만 표시한다.

## 선택과 퀴즈
- 일반 사건 선택에는 정답·오답 판정을 표시하지 않는다. 결과 서사와 인물 반응은 유지하고, 수치 피드백은 능력치 변화로 표시한다.
- 명확한 정답·오답 표시는 조교가 교육 맥락에서 출제하는 지식 문제에만 사용한다.
- 현재 모든 생활 사건 직후 퀴즈를 강제로 붙이는 구조를 제거한다.
- 퀴즈는 실제 주간·일일 훈련 과제에 연결된 별도의 교육 이벤트에서 출제한다. 해당 과제 담당 조교/교관과 문항 주제를 일치시킨다.
- 배식 사건 뒤 안전교육 문제, 분대장 추천 뒤 상황과 무관한 면접 같은 문제 등 맥락 불일치를 없앤다.
- 상황과 자연스럽게 연결되는 문제만 해당 사건에 포함할 수 있다. 문항 수를 채우기 위해 생활 사건에 삽입하지 않는다.

## 피로와 의료 사건
- 피로가 높아지면 상태 확인, 조교에게 알리기, 의무실·의무대·병원 진료로 이어지는 사건을 추가한다.
- 높은 피로를 곧바로 질병이나 입원으로 단정하지 않는다. 반복 무작위 발생을 막고, 회복과 이후 일정에 결과를 반영한다.
- 휴식과 도움 요청이 의미 있는 선택이 되게 구성한다. 훈련소 주특기 적성 고정은 유지한다.

## 인물 초상화
- 담당 조교 2명은 훈련병과 비슷한 20대 초반 외모로 교체한다. 현재 초상화는 너무 나이 들어 보인다.
- 교관은 조교와 구별되는 연령대와 외모를 사용한다.
- 동일 인물 얼굴은 기수 내에서 일관되게 유지한다.

## 다음 수정 검증
- 이전 대사 열람 시 능력치·관계 변화가 중복되지 않는다.
- 배식·분대장 추천 등 생활 이벤트에 무관한 퀴즈가 끼어들지 않는다.
- 교육 퀴즈에서만 정답 표시가 나타난다.
- 뒤로가기 추가 후에도 모바일 한 화면에서 큰 선택지에 접근 가능하다.
- 의료 사건의 조건·회복·재발 간격과 사진 나이대를 확인한다.

## 추가 피드백 — 스크롤·첫날 안내·훈련 중심
- 이벤트 생성, 대사 터치, 선택 결과 렌더링 시 페이지가 상단으로 강제 이동하는 문제를 수정한다. 현재 render()의 무조건적인 scrollTo(0,0)를 제거하고 화면 전환 종류별로 처리한다.
- 팝업 진입 전 타임라인 스크롤 위치를 보존한다. 배경 스크롤을 잠그고, 종료 후 같은 위치로 복원한다. 팝업 안의 대사·선택지를 조작해도 배경은 움직이지 않는다.
- 첫날에는 짧은 단계별 UI 안내를 제공한다: 능력치와 피로, 전역·수료 D-day, 생활 목표 직접 선택, 다음 날/자동 진행/배속, 사건 발생 시 멈춤, 대화 터치·뒤로가기·선택, 저장.
- 첫날 조작 안내에 항상 보이는 '안내 건너뛰기' 버튼을 제공한다. 건너뛰어도 게임 결과에 영향 없이 바로 진행되며, 이후 설정/플레이 안내에서 다시 볼 수 있게 한다.
- 생활 목표의 적용 기간(현재 구현은 개인정비 시간의 일별 활동)을 분명히 안내한다. 주간 목표를 채택할 경우 선택 유지 기간도 명시한다. 선택해야 할 영역을 시각적으로 강조하고 바로 조작해보게 한다.
- 사용자가 나머지 가시성은 좋다고 평가했으므로 현재 대비·큰 선택지의 방향을 유지한다.
- 훈련소의 주요 콘텐츠를 훈련·교육 이벤트로 구성한다. 생활관 서사는 훈련 사이와 그 결과에 연결한다.
- 개인화기 교육은 장비 식별·명칭·용도·안전수칙과 공개 제원 이해를 확인한다. 실제 무기 운용 능력을 높이는 구체적인 사격 절차·조준·명중 최적화 문제는 구현하지 않고, 사용자가 요청한 사격술 소재는 안전과 교육 상황 이해로 각색한다.
- 수류탄 소재는 훈련장 통제·안전수칙·이상 상황 보고 중심으로 구성한다. 구체적인 투척 기법이나 효과적인 사용 요령을 훈련시키는 문항은 넣지 않는다.
- 방독면 교육은 공개된 개인 보호·안전 자료에 근거해 착용 단계의 빈칸·순서형 문항을 준비하고, 실제 장비별 차이와 교재 근거를 확인한다.
- 정신전력 교육은 당시 공개 교재에 맞는 안보·국방의 역할 및 북한 관련 내용을 다룬다. '주적' 등의 표현은 연도·자료에 따라 달라질 수 있으므로 2013년 근거를 검증한다. 북한 정권·군과 일반 주민을 구분하며, 확인된 사실과 교재의 관점을 혼동하지 않는다.
- 모든 교육 문제에 출처·기준 연도·정답·해설을 관리한다. 등장 교관·조교, 일정, 실제로 먼저 설명한 내용과 문항을 일치시킨다.

## 빌드 반영
- 베타 0.3에 대화 뒤로가기, 내레이션·생각 괄호, 이름 아래 중복 주제 제거, 스크롤 유지·배경 잠금, 첫날 안내와 건너뛰기·다시 보기, 별도 훈련 교육, 일반 사건의 변화량 표시, 피로 상태 확인 사건, 젊은 조교 초상화를 반영했다.
- 훈련 문제는 일별 교육 일정에 연결했다. 2010 국방부 공식 설명 및 현행 민방위 보호장비 안내는 기준 연도와 각색 범위를 문제의 자료 펼침란에 표시한다. 2013년 특정 군용 방독면 세부 절차를 재현한 것으로 주장하지 않는다.
- 모바일 실제 화면 검증과 서버 배포는 기존 실행 환경 제약으로 완료되지 않았다. 다운로드 빌드로 제공한다.
